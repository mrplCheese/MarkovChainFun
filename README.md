This is a simple model (a first degree markov chain) that describes how misinformation spreads in a system.

The goal of this project was to explain that complex behavior (e.g. misinformation spreading) can be simulated and modeled computationally.
While this model is very simple, it's also incredibly fascinating. As just one portion of an English project, it demonstrated my point very clearly and in a fun way!

This project is also a small step into the world of data sonification. As the three "social media platforms" become more saturated with misinformation, the sounds produced by each platform change from one note to another.
In between the transition, you'll hear lots of white noise, that shifts "focus" from one note to another, creating a very unique transition from one note to the other.
